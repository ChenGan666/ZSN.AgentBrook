**实际实现** (与设计方案有差异，详见客户端设计方案.md 偏差表):

1. **直连 FunASR WebSocket** (不经后端代理)
   - 通过 `VITE_FUNASR_URL` 环境变量配置 FunASR 地址
   - FunASR Docker: `funasr-runtime-sdk-online-cpu-0.1.13` + `run_server_2pass.sh`
   - 使用 2pass 模式 (online + offline 双模型并发)

2. **`composables/useVoice.ts`** — 语音核心逻辑
   - Tauri 端: Rust cpal 采集麦克风音频 → base64 编码 → Tauri 事件 `audio-pcm-data` → 前端解码后发送 WebSocket
   - Web 端: AudioContext + ScriptProcessorNode 采集 PCM 16bit → 直接发送 WebSocket
   - WebSocket 自动重连 (指数退避，最多 3 次)
   - 2pass 模式识别: `2pass-online` (临时) + `2pass-offline` (最终修正)

3. **`stores/voice.ts`** — 语音状态
   - 智能文本累加: `startsWith` 检测累积文本直接替换，增量文本追加
   - 状态: idle / connecting / recording / error

4. **ChatInput.vue 直接集成麦克风按钮** (非独立 VoiceRecorder 组件)
   - 麦克风按钮 + 脉冲动画 (录音中红色闪烁)
   - 光标位置插入: 录音时分割 textarea 为 `textBeforeCursor` + `textAfterCursor`
   - 录音中实时将语音识别文本插入光标位置

5. **Tauri 音频命令** (`src-tauri/src/commands/audio.rs`)
   - cpal 原生音频采集 (非 FFmpeg sidecar)
   - PCM 16bit 16kHz 单声道

6. **类型定义** (`types/voice.d.ts`)
   - VoiceState, VoiceLanguage, FunAsrMessage
